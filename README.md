# 吉伊卡哇・糯糯大冒險 | MOCHI SURVIVOR

手機與桌面瀏覽器都能玩的像素風生存遊戲，**目前以單機離線存檔模式公開試玩**。

> **非官方、非商業粉絲創作。** 吉伊卡哇、小八貓與兔兔屬原權利人角色；非商用不代表取得授權。正式公開或長期發布前請自行確認相關授權。

## 現在就能玩

- 角色：吉伊卡哇、小八貓、兔兔，各有不同能力。
- 動作：待機、移動、攻擊、拾取/拿武器、升級、受傷、死亡。
- 操作：手機虛擬搖桿與衝刺鍵；電腦 WASD／方向鍵移動、空白鍵衝刺。
- 內容：10 種武器、5 種永久技能、10 種小怪、5 位魔王。
- 每 30 秒一波；每 5 波出現魔王戰。獲得經驗升級及過關獎勵。
- 死亡後武器、角色等級重置，永久金幣與技能則保留。

## 存檔說明

**不需要註冊、不需要 Firebase、不需要資料庫。** 使用瀏覽器的 `localStorage` 儲存永久技能、金幣、最高波次及個人戰績。

請留意：

- 不同瀏覽器或裝置的存檔**不共用**。
- 使用無痕瀏覽或清除網站資料可能導致存檔消失。
- **Google 登入、跨裝置雲端同步及全球排行榜均暫時停用**。

## 部署

這是一個不需要編譯的 HTML5 靜態遊戲；正式入口為根目錄的 `index.html`。

- GitHub 專案：[samuel8796/Mochi-survivor-](https://github.com/samuel8796/Mochi-survivor-)
- 可以部署在 Vercel、GitHub Pages 或任何支援靜態檔案的服務。
- 未來若重新啟用 Firebase，`cloud.js`、`firebase-config.js` 與 `firestore.rules` 仍保留作為開發基礎，但目前不會被網頁載入或執行。

## 開發提示

- 將網站以 HTTPS 開啟比較適合手機瀏覽器。
- 如果改變存檔格式，請考慮向下相容現有 `localStorage`。
- 排行榜如未來恢復，正式上線前應由可信任後端驗證成績，不能僅相信用戶端送出的分數。
